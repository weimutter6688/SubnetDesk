# Fork 安全清单复查

日期：2026-10-10。适用标准 Windows 配置 `flutter,hwcodec,vram`。
本报告承接[网络审查](security-network-review.md)，针对用户给出的 fork 清单复查。

| 项目 | 复查结果与处理 |
| --- | --- |
| 自动更新 | 模块此前已删除；没有保留原作者 GitHub Releases 更新通道。增加回归检查。 |
| 旧固定密码 | LAN 登录已只接受加密账号认证。本次移除 SHA-256 旧密码模块、设置/同步/验证 API；加载、写入和序列化都清除或拒绝保存旧密码字段。保留 Argon2id LAN 认证。 |
| 构建下载 | 直接下载改为固定版本和提交到仓库的 SHA-256；校验后才发布文件。删除已停用 Sciter 任务的浮动下载。USB 驱动重新下载校验与原归档一致。 |
| 共同库 | 32 个源码文件纳入主仓，与导入提交逐个比较 Git blob 一致；保留历史备份、来源和许可记录，不再依赖原作者子模块仓库。 |
| 内部命名 | 显示名保留 SubnetDesk；内部 crate、库、exe、服务、数据、钥匙串、URI、mDNS 和 MSI 升级身份隔离。握手前缀改为 fork 独立域，协议升至 v3。 |
| 上游基线 | 记录首个 LAN-only 提交的父提交，并向官方 API 核实。配置每周只读上游变更/公告巡检；基线不表示后续安全修复已全部合入。 |
| CI | 原有 Rust 测试已启用；补上共同库测试、fork 模块 fmt 和严格 Clippy/编译告警门。继承代码仍有告警，未声称全仓零告警。 |
| mDNS 隐私 | 原来已有开关但默认开启；改为明确 `Y` 才广播、回应和扫描。新配置默认关闭，保留明确设置。广播会暴露设备名、系统与指纹。 |
| 残留清理 | 删除失效的更新、固定密码、WebRTC/ICE 常量与选项列表项，清理旧配置中的这些键。语言包的历史条目按 AGENTS.md 翻译规则保留，当前 Flutter 发行界面不提供公网 ID/强制中继流程。 |
| Web 网关 | 默认关闭此前已有；默认/未知权限由 control 收紧为 view-only。只有明确选择 control/collaboration 才允许键鼠，剪贴板仍限 collaboration。 |

另发现并停用原作者签名的 `custom.txt` 信任入口：它可覆盖应用命名和设置，即使
更新器已删除仍会破坏 fork 信任边界。仅发现该入口不能证明存在恶意使用。
Clippy 还揭示键盘 DSL 错误格式化无限递归，以及 Windows 截屏/显示输出使用未初始化
值的问题；分别修复，保留针对格式化的回归测试。

本次复查未发现标准发行路径主动连接可疑硬编码公网域名、隐藏反向 shell、隐藏控制
服务器或按日期/账号触发的逻辑炸弹。可执行的网络目标仍包括用户输入的目标地址、
显式启用的发现组播、手动开启的 Web 监听，以及用户授权的隧道/文件传输。
GitHub、NASM、Google SDK 资源出现在构建与只读维护脚本中；文档/语言包中的网址
不等于程序会自动连接。可选 `plugin_framework` 仍属于额外外联功能，标准发行未启用。

验证：Rust 主库 175 通过、1 个性能报告测试默认忽略、4 个真实系统操作测试排除；
共同库在清理旧密码测试后 95 通过、1 忽略、1 个持久化 PIN 测试排除；浏览器 27 项、
错误格式化 1 项、构建下载篡改/重定向等 4 项通过。8 个维护模块的 fmt/严格 Clippy
检查通过；负向探针确认模块 deny 可以覆盖命令行对继承 Clippy 告警的放宽。
保留约 46 项主库既有编译告警。

这次未完成所有第三方依赖逐行审计、跨平台实机测试、真实双机抓包、安装/卸载或
更新后的 RDP 会话切换复现。没有证据证明完全无风险，也没有将继承代码缺陷认定为
作者恶意。默认账号密码公开记录在 README 中，应在共享网络使用前修改。

.84 Windows MSI 和两种便携包的构建记录、逐文件比较、SHA-256 与检查限制随包提供。
新旧实例同时运行需要不同监听端口；新身份不会自动复用旧账号、指纹或证书。
